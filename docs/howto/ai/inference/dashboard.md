# Accessing the {{brand_ai_inference_dashboard}}

??? note "Invite-only access"
    Access to {{brand_ai}} is currently invite-only.

To log into the [{{brand_ai_inference_dashboard}}](https://{{ai_api_domain}}), you need either a User or an Admin [API key](api-keys.md).

![Logging into the {{brand_ai_inference_dashboard}}](../assets/ai-dashboard-login_light.png#only-light)
![Logging into the {{brand_ai_inference_dashboard}}](../assets/ai-dashboard-login_dark.png#only-dark)

With a User API key, you get access to the [Playground](playground.md).
There, you can select any available model for chatting, embeddings, or audio transcriptions.

![Using the Playground Chat](../assets/ai-dashboard-user-chat_light.png#only-light)
![Using the Playground Chat](../assets/ai-dashboard-user-chat_dark.png#only-dark)

With an Admin API key, you get access to the Dashboard in addition to the Playground.
Using the Dashboard, you can review the available [models](models.md), manage your API keys, and get a detailed overview of [API and token usage](api-token-usage.md).

![API usage overview](../assets/ai-dashboard-admin-api-usage_light.png#only-light)
![API usage overview](../assets/ai-dashboard-admin-api-usage_dark.png#only-dark)
